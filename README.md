Project title: Towards causal real-life insights into mechanisms of risk and resilience for substance use: incorporating experiential interventions in everyday life
Description:
This repository contains the R scripts used for data preparation and statistical analysis of an intensive longitudinal within-person ecological momentary intervention (EMI) study. The study examined the acute effects of three randomly assigned brief interventions – cognitive reappraisal, physical activity and an active control condition (memory game) on momentary cannabis craving and loneliness in daily life. Interventions were triggered via smartphone (movisens app) when participants' craving or loneliness scores exceeded a predefined threshold during a three-week intervention phase embedded in a five-week EMA protocol.
Statistical software:

R Version: 4.4.1
Key packages: lme4, lmerTest, tidyverse, effectsize, ggplot2
